# Merge final — Comptabilité CIPRESA

La version complète de l'application métier est conservée comme base.
La navigation Comptabilité utilise maintenant un espace dédié reprenant le design comptable vert/blanc :

- Tableau de bord comptable
- Plan comptable + Nouveau compte
- Journal + Nouvelle écriture
- Grand livre
- Balance
- Bilan comptable
- Compte de résultat
- Trésorerie
- Rapprochement
- TVA & Taxes
- Immobilisations + Nouvelle immobilisation
- Clôtures

L'espace Admin reste séparé dans le menu déroulant Admin et la gestion des rôles/permissions existante est conservée.

`.env` est local et ignoré par Git. `.env.example` ne contient aucun secret.
